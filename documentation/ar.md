## إصدار الطريقة

GAD-7/Spitzer 2006: 7 بنود 0–3، مجموع 0–21؛ عتبات 5/10/15؛ برتغالية برازيلية Moreno 2016

## المعادلة الموثقة

كل بند 0 (أبدًا) إلى 3 (كل يوم تقريبًا). المجموع 0 إلى 21. عتبات الشدة: 5 و10 و15. في الدراسة الأصلية أعطت ≥10 لتحرّي القلق المعمم حساسية 89% ونوعية 82%.

## الحدود والفئة السكانية

تحرٍّ وقياس لشدة أعراض القلق المعمم لدى البالغين. تتطلب النتيجة التي تشير إلى احتمال الحالة تقييمًا تشخيصيًا. لا تثبت دراسات الرعاية الأولية والعينة المجتمعية البرازيلية تلقائيًا صلاحية الاستخدام لدى فئات جديدة أو صلاحية التنفيذ المحلي أو الترجمات الإضافية.
